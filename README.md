# Русская локализация The Guild 1 Remake: Europa 1410

Дополнительные файлы русского перевода The Guild 1 Remake: Europa 1410.

Переведены дополнительные надписи интерфейса, названия кварталов, тексты реплик и субтитры. Озвучка остаётся оригинальной.

Для игры 0.5.2.26866 (Steam) и русской локализации 1.2.1.

## Скачать

[Скачать дополнительный пакет](https://github.com/yurykolchin/guild-europa1410-russian/raw/refs/heads/main/downloads/Guild1-Russian-Extra-2026-11-04.zip)

Это предварительный пакет для проверки в игре. Возможны отдельные непереведённые строки и ошибки отображения.

## Установка

1. Подпишитесь на [русскую локализацию в Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3832058792).
2. Закройте игру.
3. Откройте папку игры через Steam: «Управление» > «Просмотреть локальные файлы».
4. В `Europa1410/Content/Paks` создайте папку `~mods`, если её нет.
5. Скопируйте в неё все три файла из архива: `ZZ_RussianExtra_P.pak`, `ZZ_RussianExtra_P.utoc`, `ZZ_RussianExtra_P.ucas`.
6. Запустите игру и выберите русский язык.

Перед обновлением файлов закрывайте игру. Для удаления дополнения уберите только эти три файла из `~mods`.

Об ошибках сообщайте в [Issues](https://github.com/yurykolchin/guild-europa1410-russian/issues). Желательно приложить скриншот и указать версию игры.

Неофициальная локализация сообщества. Сведения об использованных материалах находятся в [NOTICE.md](NOTICE.md).
