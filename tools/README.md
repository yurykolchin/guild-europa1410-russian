# Пересборка пакета

Пакет собирается из открытых JSON-файлов в `strings`. В них сохранены порядок записей, ключи, исходные CRC32 и русские тексты. Контрольные суммы ожидаемого результата находятся в `CONTENTS.json`.

Нужны Python, библиотека `pylocres` версии 0.2.0 и [repak](https://github.com/trumank/repak) версии 0.2.3. После установки зависимости из `requirements.txt` выполните из корня репозитория:

```text
python tools/rebuild.py --repak C:/path/to/repak.exe --output build
```

Скрипт создаёт три `.locres`, проверяет их SHA-256, упаковывает `.pak`, распаковывает его и сверяет все три таблицы побайтно с опубликованными. Служебные `.utoc` и `.ucas` копируются из `package` с проверкой контрольных сумм. Пересобранный `.pak` может иметь другую контрольную сумму контейнера; содержимое всех трёх вложенных `.locres` должно совпадать побайтно. Контрольные суммы готовых файлов для обычной установки приведены отдельно в `CHECKSUMS.txt`. Скрипт не устанавливает их в игру.
